# Resolve conflicted copies and recover deleted files

## Conflicted copies
When two people edit a file offline, VeloSync keeps both. The second version is renamed `Report (Dana's conflicted copy 2026-07-01).docx`. Compare the two, merge your changes, and delete the copy you no longer need.

## Restoring an earlier version
On the web, right-click the file and select **Version history**. Retention depends on plan:

| Plan | Version history | Deleted file recovery |
|------|-----------------|-----------------------|
| Personal | 30 days | 30 days |
| Team | 180 days | 90 days |
| Enterprise | 365 days | 180 days |

## Recovering deleted files
Open **Trash** on the web, select the files and choose **Restore**.

## Mass deletion or ransomware
Do not try to fix this manually. Stop sync on every device immediately by selecting **Pause**, then contact support and ask for a **library rollback**. Rollback is performed only by Veloria support and requires an account owner to approve it. See KB-5001 for how to escalate.
